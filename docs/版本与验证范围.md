交付日期2026年10月13日，版本1.0。题目为申报资料解析与文案生成智能体。公开仓库：https://github.com/ShanHuiSir/application-advisor-agent 。

## 已验证

- 真实DeepSeek function calling提取2个虚构项目：智能制造研发专项100%，符合五项形式条件；重点攻关储备专项60%，不符合。不是获批概率。
- 储备专项差距：有效发明专利2项、研发占比1.2个百分点。对输入阈值使用Decimal比较。
- 独立验收规划正文4324个中文字；视频实际新建记录正文3899个中文字。两次生成随机性允许文案不同，字数、记录ID和模型响应保存在各自JSON。
- 16项离线测试，覆盖资格数值边界、未知及无法表示的硬条件、原文数值、日期/时刻/时区、财务年度、词法RAG、ICS、到期提醒去重、历史持久化及Word章节完整性与ZIP哈希。
- Windows GitHub Actions通过16项测试、Win32窗口创建销毁、Windows便携构建、嵌入式运行时模块导入和原生窗口冒烟。公开日志见Windows验证记录.json及Actions。CI是基础运行验证，不等于在不同真实Windows用户桌面完整操作过。
- 实际浏览器文件导入、模型解析、文字输入、结果滚动、日历、基于证据问答和整包下载。视频本轮记录ID c3d0dd687dd1495ca0d94bfdfa141499；每个导出文件提供SHA256。
- 中文DOCX以LXGW WenKai字体配合本地LibreOffice渲染，冒烟确认中文正文、标题及表格。项目申报书、独立验收Word和视频本轮Word经过源文完整性检查及逐页视觉检查。

## 数据与性能口径

输入均为虚构的指南和企业。资助上限80/150万元、营收1800万元、研发比例4.8%、专利3项、2026年11月至12月截止节点是模拟事实，不对应现实政府政策或真实企业。文案中的技术路线、实施安排和效益建议是规划，缺失预算、履历和性能指标由企业确认。

模型耗时与token用量见每次实际response记录；未以单次小样例推算生产并发、准确率、年均节省工时或真实投资回报。12MB及12万字符是输入约束，未完成该上限的压力基准测试。最长文本也受模型上下文额度限制，超出provider限制时会明确报错。

## 尚未验证或未实现

扫描PDF OCR、任意政策复杂或条件、跨年度财务换算、系统关闭后的自有后台提醒、微信/短信/移动端推送、官方模板精确对齐和签章、最终主管部门批准。引用校验检查原文存在性与部分数值，不是对整篇文案事实的全面自动核验。正式申报应人工逐项复核。

浏览器通知需要授权及打开工作台；客户端运行期间自动检查，关闭后不检查。ICS是否触发DISPLAY闹铃由导入的日历软件决定，本次验证ICS结构和UTC时间值，没有声称实测所有日历客户端。
