# 本地部署与操作手册

评委最快体验路径是Windows免安装包：解压到有写权限的目录，双击启动批处理，在模型设置填入自己的DeepSeek Key，再选择样例政策与企业档案。客户端管理窗口是Windows原生窗口，业务工作台使用默认浏览器。关闭管理窗口会结束本地服务和提醒。

## Windows免安装版

适用Windows 10/11 x64。打包内含官方CPython 3.12.10嵌入式运行时、python-docx、pypdf、lxml、typing_extensions和tzdata，无需在电脑另装Python。解压后执行 `启动申报参谋.bat`；若没有正常打开工作台，运行 `诊断启动.bat`查看错误。

服务只监听127.0.0.1:8891。如端口已被占用，应关闭旧客户端后重试。源码可用环境变量ADVISOR_PORT切换端口；当前原生启动器的按钮固定打开8891，便携版本建议保持默认端口。

首次填入Key可勾选保存至本地.env，也可以在启动前设置环境变量DEEPSEEK_API_KEY。未勾选保存时Key仅驻留本次服务进程。网络仅用于模型API推理；上传的选定政策和企业内容会发送给DeepSeek，运行记录保存在本机runtime/advisor.sqlite。

## 源码运行

需要Python 3.11或更新版本。运行 `python -m pip install -r requirements.txt`，然后 `python app.py`。macOS/Linux访问工作台URL；Windows可使用 `python desktop_native.py`或源码批处理。可选Tk入口desktop.py需要完整Python安装自带的Tk，免安装版采用Win32入口，无Tk依赖。

## 操作顺序

1. 在资料与画像选择政策文件和企业档案，也可载入模拟案例。文本要求UTF-8，支持TXT/MD、企业JSON、DOCX和可提取文字PDF。PDF扫描件需先OCR并人工核对。文件12MB，文本12万字符上限。
2. 点击解析政策并匹配企业。真实模型请求通常需要数十秒，网络和文档长度会影响耗时。失败时直接显示错误，不会自动使用模拟回答。
3. 查看项目匹配，逐条件核对政策原文、企业数值、通过状态及补足建议。仅有格式条件达标不代表批准；截止日期在政策日历单独核对。
4. 在文案与附件选择项目，填写写作要求。生成后查看正文中文字符数、各章节及原文索引。未提供的预算、履历、专利名称与性能指标由企业确认，生成文件状态为待人工复核草稿。
5. 政策日历列出所有项目的网报与纸质节点。客户端运行期间每分钟自动检查；浏览器通知需点击启用并允许权限。关闭应用后可由导入ICS的日历接管提醒，取决于日历软件是否支持DISPLAY闹铃。
6. 证据问答基于当前资料召回原文再回答，引用可展开。资料中没有答案时应提示无法确认。
7. 导出成果整包，解压得到Word草稿、MD规划、CSV附件清单、ICS、JSON证据和文件SHA256。历史记录可在重启后恢复和再次导出。

## 企业JSON口径

样例字段：name名称、location注册地、company_age成立年限、revenue_wan营收万元、rd_ratio研发占比百分数、patents有效发明专利项数、staff人数、assets_wan资产万元、period财务年度、project_name拟申报项目名称、business业务描述。4.8%填写4.8，不能填写0.048。缺失字段填写null或省略。业务人员应核对年度、专利有效性和财务口径；当前没有自动跨年度换算。

## Word字体

交付示例采用开源霞鹜文楷LXGW WenKai，整包附字体与OFL许可。为了保持示例排版，可安装该字体；字体不可用时Word会选择系统替代字体。中文已在本次LibreOffice渲染环境经过冒烟和逐页检查，目标Windows Office的具体替代字形仍需实际查看。

## 故障与维护

HTTP401/403通常表示Key无效或权限问题，429可能为配额或限流，网络错误请检查代理和DeepSeek可达性。原文证据校验失败表示模型输出未通过门禁，建议检查原文并重试；复杂条件需人工判断。任务仅驻留本次进程，服务重启后未完成任务不恢复，但已完成分析保存在历史中。

备份runtime/advisor.sqlite可保留已完成分析和提醒记录。删除本地.env后重启可清除本地Key配置，删除runtime会清空本地历史。正式使用前由企业确认数据处理方式、原文有效性和官方申报模板。
