# 需求与验收对应

以用户提供的“申报资料解析与文案生成智能体”题目文件为需求参考。材料中的示例项目名、85分和2026年5月日期是示例，不作为实际运行结果。用户明确要求带自然中文神经语音和字幕的真实操作MP4，以及公开GitHub交付，已列入交付范围。

| 要求 | 实现 | 验收证据 |
|---|---|---|
| 长文本政策导入与关键要素 | TXT/MD/DOCX/文字PDF，主体条件、资助、日期、附件 | 原文引用与真实模型验收JSON |
| 企业画像与项目匹配 | 注册地、年限、营收、研发占比、专利等字段逐项比较 | 虚构企业及2项目；100分和60分 |
| 差距分析 | 数值差距与建议，不用模型决定差额 | 储备专项缺2项专利、缺1.2个百分点 |
| 文案与材料清单 | 正文超过1000中文字符，附件CSV | Word草稿、MD规划与CSV |
| 生命周期追踪 | 北京时间节点、7/3/1天提醒、ICS | 日历UI、ICS测试与提醒去重测试 |
| 大模型Agent | DeepSeek命名函数工具调用，工作流控制与结果门禁 | 模型名、工具名、token用量、response ID |
| RAG | 本地原文分块、中文双字召回、块ID引用 | 索引策略文档与视频证据问答 |
| Windows桌面为主 | 原生Win32入口及嵌入式免安装包 | GitHub Actions Windows测试与入口冒烟 |
| 完整最终申报书加分项 | 一键可编辑Word草稿，章节完整 | 可作为加分参考，但未集成主管部门正式模板，不主张“最终版”已完成 |
| 微信/移动端提醒加分项 | adapter事件契约设计 | 仅设计，未接入，未验证外部推送 |
| 工程与本地部署 | 全源码、依赖、Windows便携包、手册 | 源码ZIP与公开仓库 |
| 视频 | 持续浏览器操作真实截图序列、神经语音、同步字幕 | MP4、解说词、SRT及视频实测JSON |
| 2026年5月31日前提交 | 本项目实际2026年10月完成 | 不主张已过期时效加分 |

本项目验收覆盖明确虚构的数据集，不代表在真实政企环境的全面准确率。未经证据核验的官方申报条件、预算和效益目标，仍需人工确认。申报书参赛信息：黄炜皓、广东科技学院、（联系方式见本地完整申报书）。
